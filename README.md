#🎯NUMBER GUESSING GAME
**A beginner-friendly python project**
created to practice basic python programming concepts.
## TECHNOLOGIES USED
- 🐍 python
- 🎲 random module
## 📚 python concepts practiced
- variables
- user input
- Conditional statements
- While loops
- Functions
- Random number generation
- Input validation
## HOW IT WORKS
The computer randomly selects a number between 1 and 100.
the player enters guesses, and the program gives hints:
- Too low
- Too high
- Out of bounds
- Correct number
The program also counts the number of attempts.
## WHAT I LEARNED
Through this project, I practiced python fundamentals and learned how to combine user input, condition loops, and the random module to create a simple interactive program.
